# Em execução

Decisões concretas que já foram tomadas e estão sendo tocadas.

Esta é a **fonte da verdade**. Se algo aqui contradiz qualquer coisa nas outras pastas,
o que vale é o que está aqui.

Só entra aqui o que você de fato **decidiu e está fazendo**. Quando uma decisão muda,
atualize o arquivo aqui mesmo — assim a IA sempre te acompanha no pensamento mais atual.
