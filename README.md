# Mesa

Este é o lugar onde o Luiz organiza o que pensa, separado em **três níveis de maturidade**.

## Por que isso existe

Muitas vezes uma ideia começa solta na cabeça, vai amadurecendo, e às vezes muda
completamente. Mudar de ideia é normal e saudável. O problema é quando alguém (ou
uma IA) fica preso numa coisa antiga que você já não pensa mais.

Este sistema resolve isso: ele deixa **claro o que é só um pensamento solto** e o que
**já é uma decisão tomada**. Assim, quando você conversa com a IA (Claude), ela sabe
qual é o seu pensamento **atual** — e não fica te puxando de volta para ideias velhas
que você já abandonou.

## As três pastas

### `caixa-de-entrada/`  — tudo cru
Você joga aqui o que veio na cabeça, do jeito que veio. Sem filtro. Pode ter ideia
repetida, contraditória ou meia-boca. Tudo bem: o objetivo é só tirar da cabeça.

### `refinado/`  — o que faz sentido
Depois de reler a caixa-de-entrada com calma, o que realmente vale a pena vem pra cá,
já mais organizado. É o seu pensamento atual, peneirado.

### `em-execucao/`  — decidido e em andamento
O que virou decisão concreta e já está sendo tocado. **Esta pasta é a fonte da
verdade.** Se algo aqui contradiz qualquer coisa nas outras, o que vale é o que está
aqui.

## A regra mais importante

Quando houver qualquer contradição entre as pastas, **o nível mais alto sempre vence**:

```
em-execucao/   >   refinado/   >   caixa-de-entrada/
 (decidido)        (filtrado)        (cru, solto)
```

## Como usar no dia a dia

1. Teve uma ideia? Joga na `caixa-de-entrada/` sem pensar muito.
2. De vez em quando, releia e mova o que faz sentido para `refinado/`.
3. Quando decidir de verdade e começar a executar, leve para `em-execucao/`.
4. Mudou de ideia? Atualize o arquivo no nível certo. O sistema (e a IA) te acompanham.
