# Caixa de entrada

Tudo cru, do jeito que veio na cabeça. Sem filtro, sem julgamento.

Aqui pode ter ideia repetida, contraditória, meia-boca ou genial. Tudo bem. O objetivo
é só **tirar da cabeça** e registrar.

Nada aqui é definitivo — é matéria-prima. Quando uma ideia amadurecer, ela sobe para a
pasta `refinado/`.
